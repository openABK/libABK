Event List

This List shows all events from the server. These events have the folowing elements:
  1. Sender: Addresse of origin of the event
  2. Time: Locale time when the event was fired by the server
  3. EventType: Type of event
  4. Role: The role of the client the event is ment for. Used to filter events in multi-client environments
  5. StringParam: String Parameter passed along the event
  6. Param1, Param2: Numeric parameters passed along the event
